1 · 一句话目标

建设矿浆管道专家系统：三维数字孪生展示 + 物联网采集为底座，覆盖监测诊断、智能预警、告警工单、水力计算与数据治理；原型 Vue3 + Mock，真 3D / 真算法 / 真 OPC 不做。

2 · 范围

要做：顶栏双选项卡（项目管理 / 孪生展示）；标书 12 模块 + 物联网配置 + 告警工单 + 离线模拟 + 知识库；原专家系统功能并入对应模块；角色仅超管/主管/访客
不做：真 OPC / 补传 / 水力求解 / 3D 引擎 / 架构验收页 / 性能压测页
可加做：接口契约页、更细权限矩阵、桥接映射可视化

3 · 角色权限表

角色功能权限数据权限操作权限
超级管理员全部菜单（含账户/知识库审核发布）全部项目增删改查、告警确认、导出、离线演练
项目主管所绑项目菜单（无账户管理；知识库可编辑提交审核）所绑项目读写改配置、确认告警、派工单、导出；不可删账号
访客所绑项目只读菜单（无账户管理；知识库只读）所绑项目只读查看孪生/告警/报表；不可确认告警、不可改参

4 · 技术栈

Vue 3 + Element Plus 风格模拟 + Mock 假接口（不做后端）；B/S 浏览器访问；WebSocket 推送 Mock

5 · 页面风格

蓝色模拟后台：主色 #409EFF，侧栏 #001529，内容区 #f0f2f5；含折叠侧栏、弹窗、抽屉；非线稿。

6 · 全局约定

报警：红三级紧急 / 橙二级风险 / 蓝一级关注；声光可静音；红未确认闪烁
精矿/尾矿为独立数据空间（各有配置库副本 + OPC 映射归属）。顶栏旁显示当前项目与通讯模式；孪生页可切换项目。工艺节点点选后左右栏只显示该节点。
产品通讯模式二选一：本地仿真（配置库+算法，OPC 关）/ OPC（真采集，优先 UA）。配置主数据（铭牌/几何/限值）与 OPC 运行量分层；基础参数/设备接入/标签映射已灌原库真实样本。Mock 仅本 HTML 原型交付手段，不进产品开关。不做 TKN/Modbus。设备类型对齐原项目，不含 LP/SP/RV/AV/OS/IM。写回（启停/设定）原系统有点表但本交付默认不做遥控。
角色仅超级管理员 / 项目主管 / 访客；顶栏左侧系统名与选项卡同水平。
告警升级默认时限：一级关注 30 分钟 / 二级风险 2 小时（可按项目改）
真 3D 一律占位；纵断面可替代
